# Chifa Cristal – Landing NFC

Carta digital, reservas y opiniones de Chifa Cristal (local Chorrillos).

- `chifacristal/index.html`: la landing. Datos editables en los bloques CONFIGURACIÓN, CARTA y FOTOS.
- `chifacristal/img/`: portada y fotos de platos.
- `r/…`: enlaces cortos para etiquetas NFC y códigos QR (ej. `r/cc-ch` = local Chorrillos, `r/cc-ch-07` = mesa 7).
- `_redirects`: las mismas redirecciones para Cloudflare Pages (GitHub Pages lo ignora).

Publicado con GitHub Pages desde la rama `main`, carpeta raíz.
